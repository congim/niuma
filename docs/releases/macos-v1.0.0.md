# 牛马脱敏器 macOS v1.0.0

首个原生 Mac 版本，支持 macOS 13 或以上。

## 下载

| Mac 类型 | 安装包 |
| --- | --- |
| Apple 芯片（M 系列） | `NiuMa-macOS-arm64-1.0.0.dmg` |
| Intel 芯片 | `NiuMa-macOS-x86_64-1.0.0.dmg` |
| 同时兼容两种芯片 | `牛马脱敏器-macOS-universal.zip` |

打开对应的 DMG，将「牛马脱敏器.app」拖到「Applications」后打开。应用入口在屏幕顶部菜单栏的钞票图标，不显示 Dock 图标。Universal ZIP 解压后也可将应用拖入「应用程序」。

`SHA256SUMS.txt` 提供上述三个文件的 SHA-256 校验值。

## 功能

- 按日薪或月薪实时计算今日已赚，滚轮数字，午休与加班计算。
- 上下班倒计时、工时进度、月累计估算、发薪日和心愿单。
- 原生悬浮窗、菜单栏、迷你模式、防窥、置顶、拖动吸附和鼠标穿透。
- 自定义作息、工作日、背景、透明度、语录和临时调休。
- 通知和登录启动默认关闭，可在设置中自行启用。
- 全局快捷键：`Control + Option + M/H/T`，分别用于显示窗口、防窥和穿透。

## 验证与限制

- 59 项核心检查和原生 AppKit 窗口检查通过；x86_64 核心检查已在 Rosetta 下执行通过。
- Apple 芯片 Mac 已检查真实界面、实时递增、迷你模式、防窥及设置保存/取消。
- 两个 DMG 均验证镜像、架构、应用签名、安装入口和内置 MIT 许可证；安装包随附校验和。
- 当前使用本地 **ad-hoc 签名**，**尚未经过 Apple Developer ID 签名和公证**，首次打开可能受到 macOS 安全检查限制。
- Intel 硬件、macOS 13 实机、多显示器、真实全局按键、系统通知和登录启动仍待实机验收。
- 月累计按历史工作日满勤估算，不记录历史考勤及历史加班；不支持跨夜班次。

源代码发布在 `codex/macos-version-20261110` 分支，并由 `macos-v1.0.0` 标签固定。完整验证记录见同一标签下的 `docs/macos-validation.md`。
