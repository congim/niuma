# 牛马脱敏器 macOS v1.1.0

这一版围绕上班时的轻量陪伴体验更新，让今日收入、下班期待和生活小心愿更容易看清。适用于 macOS 13 或以上。

## 更新内容

- 重排悬浮窗的信息层级，突出滚动收入和下班倒计时，采用暖色纸感、独立收入卡与牛马点缀。
- 增加首次薪资设置引导。选择“先看示例”即可体验，示例金额在主屏、迷你模式和战报中都有标识。
- 设置分为“收入与作息”“桌面外观”“心愿与提醒”，输入薪资与作息时即时显示计算预览。
- 月计薪天数、午休时间和加班倍率随对应选项启用，输入错误会提示，跨组编辑统一保存。
- 迷你模式加入下班倒计时，防窥与置顶按钮显示当前状态，主屏提供复制战报入口及反馈。
- “本月预估”明确收入估算口径，心愿提示使用“再计薪多久”表达剩余计薪时间。
- 升级时读取已有设置，并将旧版配置识别为已完成薪资设置。

## 下载与安装

| Mac 类型 | 安装包 |
| --- | --- |
| Apple 芯片（M 系列） | `NiuMa-macOS-arm64-1.1.0.dmg` |
| Intel 芯片 | `NiuMa-macOS-x86_64-1.1.0.dmg` |
| 同时兼容两种芯片 | `NiuMa-macOS-universal-1.1.0.zip` |

打开对应的 DMG，将“牛马脱敏器.app”拖到“Applications”后打开。升级前先退出旧版，再替换应用。应用入口位于屏幕顶部菜单栏的钞票图标。

`SHA256SUMS.txt` 提供两个 DMG 和 Universal ZIP 的 SHA-256 校验值。

## 验证范围

- 发行前执行 arm64 和 x86_64 核心回归，每种架构 65 项检查。x86_64 检查在 Rosetta 下运行。
- 发行前核对双架构构建、最低系统版本、应用签名、DMG 内容、ZIP 完整性与安装包校验值。
- 开发阶段完成首用设置、即时预览、错误恢复和设置分组的真实界面检查，并执行原生回归。最后补充的统一复制反馈完成编译与静态检查，前台交互仍待复测。

## 使用说明与限制

- 应用采用本地 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。首次打开可能受到 macOS 安全检查限制。
- 月预估按历史工作日满勤计算，历史考勤和历史加班尚未纳入模型。班次需在同一天内。
- Intel 硬件、macOS 13 实机、多显示器、系统通知与登录启动仍待实机验收。

源代码由 `main` 分支发布，并以 `macos-v1.1.0` 标签固定。应用内部版本为 `1.1.0`，构建号为 `2`。
