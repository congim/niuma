# 牛马脱敏器 macOS 移植设计

目标：在独立分支交付可直接打开的 macOS 应用，保留 Windows 版的用途、纸张背景和薪资规则。

## 项目分析

- `src/Engine.cs` 是按本地日期计算的纯业务逻辑：日薪/月薪、工作日、单日调休、午休扣除、加班、发薪日、心愿单。
- `src/Settings.cs` 用反射读写 Windows AppData 下的 INI。没有数据库或远端服务。
- `src/MainWindow.cs`、`src/Odometer.cs`、`src/SettingsWindow.cs` 使用 WPF；入口及原生辅助位于 `src/App.cs`。
- 窗口置顶、穿透、托盘、全局快捷键和注册表自启动均依赖 Windows，不能通过修改编译目标运行在 macOS。
- `build.ps1` 直接调用 .NET Framework 编译器，无项目文件、第三方依赖或现成测试。

## 方案

1. **原生 Swift + AppKit（本次采用，实施判断）**：直接使用系统窗口和菜单栏能力，包体小，不引入运行时；业务规则需要逐项移植并测试。
2. 跨平台 .NET UI：可复用部分计算代码，但必须重做 UI、引入框架和运行时；对于当前规模收益较小。
3. Web 容器：仍需实现原生穿透/快捷键/自启动桥接，增加依赖和包体。

用户授权范围是分析、切分支、制作 Mac 版本；没有要求发布或提交远端。

## 范围与约束

- macOS 13+，构建 arm64/x86_64 Universal `.app`；只使用系统 Swift / AppKit / Carbon / UserNotifications / ServiceManagement。
- Windows 源码、资源及编译脚本保持原样。
- 保留实时金额和滚轮、六种工作状态、进度、月累计、发薪日、心愿单、语录。
- NSPanel 实现置顶、拖动、贴边、全屏辅助空间、迷你模式、穿透；NSStatusItem 保证隐藏或穿透后仍可恢复。
- 全局快捷键采用 Control+Option+M/H/T，冲突时显示提示，菜单栏仍可操作。
- 原生设置包括薪资、时间、工作日、显示、透明度、背景、语录、心愿单、通知和登录启动；取消放弃修改，保存前完整校验。
- 配置为 `~/Library/Application Support/NiuMaTuoMinQi/settings.json`，原子写入；无效配置报告错误，不能自动覆盖损坏的原文件。
- 防窥同时遮蔽今日、月累计、时薪、赚钱速度、目标差额及导出的战报。
- 月累计延续原版估算，不增加考勤记录、历史加班数据库、云同步或货币换算。
- 登录启动只在用户勾选后调用系统服务；首次启动不主动注册或弹通知授权。
- 无开发者证书时本地 ad-hoc 签名，交付明确区分本机验证、Intel 编译和签名公证。

## 验证

纯 Swift 测试覆盖时间边界、午休、月薪、调休到期、短月/跨年发薪日、心愿单、设置校验与原子读写、数字进位。构建脚本验证两种架构和资源封装。原生 smoke 测试覆盖窗口、迷你、防窥、穿透、菜单、设置保存/取消及多实例；测试配置使用临时目录。启动真实 `.app` 检查 UI 后关闭本任务创建的进程。
